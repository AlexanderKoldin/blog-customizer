# Blog Customizer

Страница статьи с боковой панелью настроек: читатель меняет шрифт, размер и цвет текста, цвет фона и ширину контента.

**Стек:** React 18 · TypeScript · SCSS Modules · Webpack · Storybook · ESLint · Stylelint · Prettier

## Как работает

- Панель открывается по кнопке-стрелке и закрывается повторным нажатием или кликом вне панели (обработчик `mousedown` на документе вешается только пока панель открыта и снимается при закрытии).
- Изменения в форме не применяются сразу. Состояние формы и состояние страницы хранятся отдельно: кнопка **«Применить»** переносит настройки на статью, **«Сбросить»** возвращает значения по умолчанию и в форме, и на странице.
- Стили статьи меняются через CSS-переменные (`--font-family`, `--font-size`, `--font-color`, `--bg-color`, `--container-width`), которые выставляются на корневом элементе, поэтому сама статья не знает о настройках.
- Форма собрана из UI-компонентов (`Select`, `RadioGroup`, `Button`, `Separator`, `Text`), задокументированных в Storybook.

## Запуск

```bash
npm install
npm start            # dev-сервер
npm run build        # продакшен-сборка
npm run storybook    # каталог UI-компонентов
npm run lint         # ESLint
npm run stylelint    # Stylelint
```
